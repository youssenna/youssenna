# Call Me Maybe — Function Calling in LLMs

</summary>

An implementation of function calling for small LLMs: converts natural language prompts into structured, typed function calls using **constrained decoding** (token-level logits masking driven by a parser state machine), guaranteeing 100% schema-valid JSON output — no retries, no malformed responses.

| Category | Details |
|-----------|---------|
| **Stack** | Python 3.10+ • Pydantic • Hugging Face Transformers • `uv` |
| **Model** | Qwen3-0.6B (bonus: Qwen2.5-1.5B-Instruct) |
| **Core Technique** | Logit masking via a JSON parser state machine — invalid tokens set to `-inf`, forcing schema-valid output at every step |
| **Performance** | Re-encoding bottleneck fixed by working entirely in token-ID space — cut runtime by over 90% |
| **Reliability** | Pydantic input validation, safety limits against repetition loops, dynamic schema parsing for any function definition |
| **Repository** | [github.com/youssenna/call-me-maybe](https://github.com/youssenna/call-me-maybe) |

### Highlights

- Constrained decoding via real-time logits masking
- Parser state machine tracking JSON generation state
- Dynamic schema parsing — works with any function definitions
- Pre-computed token ID caching for fast lookups
- 100% schema-compliant JSON output, by construction

</details>
